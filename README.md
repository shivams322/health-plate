# Health Plate

Indian food, water and meal-timing tracker: 370 foods and 20 protein powders, targets from your body and weekly exercise, meal balance, streaks and badges. One codebase runs as a **website** (installable, works offline) and as **Android** and **iOS** apps (via Capacitor).

Everything a person logs stays on their own device. There are no accounts, no server and no tracking. People can download a backup and restore it under **My targets → Your data**.

## What's in this folder

| Path | What it is |
|---|---|
| `web/` | The website and the app's screens. `web/index.html` is the whole app. |
| `web/privacy.html` | Privacy policy, needed for both app stores. |
| `web/sw.js`, `web/manifest.webmanifest` | Offline support and "Install app" for the website. |
| `android/` | Android Studio project (generated by Capacitor). |
| `ios/` | Xcode project (generated by Capacitor). |
| `assets/` | Source images for app icons and splash screens. |
| `scripts/` | Helpers: local server, fonts, icons. |
| `codemagic.yaml` | Cloud builds for Android and iOS (no Mac needed). |
| `netlify.toml` | Website hosting settings for Netlify. |

## Run it on your computer

```
npm install
npm run serve
```

Then open http://localhost:8080.

## Try it on your phone over Wi-Fi (nothing to install)

```
npm run serve:lan
```

It prints an address like `http://192.168.1.5:8080`. Open it on any phone connected to the same Wi-Fi, Android or iPhone. If Windows asks, allow Node.js on private networks. On the phone you can use *Add to Home screen* to get an app icon. Offline mode only starts once the site is live on `https://`.

## Run the Android app locally (works on this Windows PC)

1. **Install Android Studio** from https://developer.android.com/studio. Choose *Standard* setup on first launch. It installs the Android SDK, an emulator and Java 21, which Capacitor 8 needs.
2. **Pick where to run it:**
   - **Emulator:** in Android Studio, open *More actions → Virtual Device Manager → Create device*. Pick a recent Pixel and a recent system image, then press ▶ to start it.
   - **Your own phone:** go to *Settings → About phone* and tap *Build number* 7 times. In *Developer options*, turn on *USB debugging*. Plug the phone in by USB and tap *Allow* on the phone.
3. **Run Health Plate** from this folder:
   ```
   npx cap sync android
   npm run android:run
   ```
   Choose the emulator or your phone from the list. Or run `npm run android` to open the project in Android Studio and press the green ▶ Run button.
4. **After you change files in `web/`,** run `npx cap sync android` again and re-run.
5. **To share a test copy** with friends, use *Build → Build App Bundle(s) / APK(s) → Build APK(s)* in Android Studio. Send them `android/app/build/outputs/apk/debug/app-debug.apk`; they allow "install unknown apps" to open it.

## Run the iOS app locally

Apple only lets iOS apps be built and run with **Xcode on a Mac**. Windows can't run the iPhone simulator.

**On a Mac:**

1. Install Xcode from the Mac App Store and open it once to finish setup.
2. Copy or clone this folder to the Mac, then run:
   ```
   npm install
   npx cap sync ios
   npm run ios:run
   ```
   Choose an iPhone simulator from the list. Or run `npm run ios` to open Xcode and press ▶.
3. **To run on your own iPhone:**
   - Plug it in, and in Xcode select *App → Signing & Capabilities*.
   - Set *Team* to your Apple ID. A free Apple ID works for your own phone, but the app stops opening after 7 days until you run it again from Xcode.
   - On the iPhone, turn on *Settings → Privacy & Security → Developer Mode*.

**Without a Mac:**

- **Use the website on your iPhone.** Once the site is live, open it in Safari, tap *Share → Add to Home Screen*. It opens full-screen with its own icon, works offline, and keeps data on the phone, much like the app.
- **TestFlight via Codemagic** (section 4). This needs the Apple Developer Program.
- **Rent a cloud Mac by the hour** (for example MacinCloud) and follow the Mac steps.

## Before you launch

1. **Add your contact email** in `web/privacy.html` (search for "add your contact email").
2. **Check the name.** Search the Play Store, App Store and domain sites for "Health Plate".
3. **App ID.** The apps use `com.healthplate.app`. If you own a domain, change it now to match (for example `in.yourdomain.healthplate`) in `capacitor.config.json`, `android/app/build.gradle` (namespace and applicationId) and `codemagic.yaml`. It can't be changed after the first store upload.

## 1. Put the website live (GitHub Pages)

The site is published from the `web/` folder by `.github/workflows/pages.yml` every time you push to the `main` branch. The address is `https://<your-github-username>.github.io/health-plate/`.

**One-time setup:**

1. Create a **public** repository named `health-plate` on GitHub. The free plan only publishes Pages from public repositories, so anyone can see the code. No one's personal data is in it, because each person's log stays on their own phone.
2. Push this folder to it.
3. In the repository, go to *Settings → Pages → Build and deployment → Source* and choose **GitHub Actions**.
4. Open the *Actions* tab and wait for "Deploy website to GitHub Pages" to finish, then open the address above.

**Updating the site:** change files in `web/`, bump `VERSION` in `web/sw.js`, commit and push. The site updates in about a minute.

**Your own domain (optional):** in *Settings → Pages → Custom domain*, enter something like `healthplate.in`, then add the DNS records GitHub shows you at your domain registrar.

Your privacy policy lives at `https://<your-github-username>.github.io/health-plate/privacy.html`. Both app stores ask for this link.

Netlify and Cloudflare Pages also work if you prefer. `netlify.toml` is already set up to publish `web/`.

## 2. Android app (Google Play)

**You need:** a Google Play developer account (one-time USD 25 fee), plus either Android Studio on this PC or the Codemagic cloud build.

**Build on this PC**

1. Install Android Studio from https://developer.android.com/studio. It includes the Android SDK and Java 21, which Capacitor 8 needs.
2. Run `npx cap sync android`, then `npm run android` to open the project.
3. To try it, plug in your phone with USB debugging on and press Run.
4. To release: *Build → Generate Signed Bundle / APK → Android App Bundle*. Create a new upload keystore when asked. **Back up the keystore file and its passwords.** You need them for every future update.

**Or build in the cloud:** see section 4.

**Publish**

1. In Play Console, create the app "Health Plate".
2. Fill in the store listing (description, screenshots, icon from `assets/icon-only.png`).
3. App content:
   - Privacy policy URL.
   - Data safety: *No data collected* and *No data shared*.
   - Health apps declaration: general nutrition tracking, no medical claims.
   - Content rating and target audience (adults).
4. Upload the `.aab` to a testing track. New personal developer accounts must currently run a closed test with at least 12 testers for 14 days before releasing to production; check Play Console for the latest rule.

## 3. iOS app (App Store)

**You need:** an Apple Developer Program membership (USD 99 a year). To build, use either Codemagic (section 4, no Mac needed) or a Mac with Xcode.

1. In https://developer.apple.com, register the bundle ID `com.healthplate.app`.
2. In App Store Connect, create the app "Health Plate".
3. Build and upload, either with Codemagic or on a Mac:
   - **Codemagic:** run the `ios-release` workflow. It signs the app and sends it to TestFlight.
   - **Mac:** run `npm install && npx cap sync ios && npm run ios`, set your team under *Signing & Capabilities*, then *Product → Archive → Distribute App*.
4. Test it on your iPhone through TestFlight.
5. Fill in the App Store listing:
   - Screenshots.
   - Privacy policy URL.
   - App Privacy: *Data Not Collected*.
   - In the review notes, say the app gives general nutrition guidance and stores data only on the device.
6. Submit for review.

## 4. Cloud builds with Codemagic (no Mac needed)

1. Put this folder on GitHub (private is fine) and sign in to https://codemagic.io with GitHub.
2. Add the repository. Codemagic reads `codemagic.yaml`.
3. **Android:** upload your keystore under *Team settings → Code signing identities* and name it `health_plate_keystore`.
4. **iOS:** under *Integrations*, add an App Store Connect API key named `health_plate_asc`. Codemagic then creates the certificates and profiles for you.
5. Start the `android-release` or `ios-release` workflow. You download the `.aab` for Google Play; the iOS build goes straight to TestFlight.

## Updating the app later

1. Edit files in `web/`. `web/index.html` holds the screens, food list and logic.
2. In `web/sw.js`, change `VERSION` (for example to `health-plate-v2`) so websites pick up the change.
3. Run `npx cap sync` to copy the change into the Android and iOS projects.
4. For a store update, raise the version: `versionCode`/`versionName` in `android/app/build.gradle`, and the version in Xcode. Codemagic sets build numbers automatically.
5. If you change `assets/` or the icon design: run `npm run icons`, then `npm run assets`.

## Data and sources

- Targets: Mifflin-St Jeor energy equation; ICMR-NIN 2020 recommended dietary allowances.
- Food values: IFCT 2017 and USDA ingredients, the Indian Nutrient Databank (INDB 2024), and brand labels for protein powders.
- Fonts: Baloo 2, Mukta and IBM Plex Mono (SIL Open Font License), bundled through @fontsource.

Health Plate gives general guidance for healthy adults. It is not medical advice.
